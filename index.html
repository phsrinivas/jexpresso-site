Jexpresso
Home Gallery Install Documentation About GitHub

A CPU and GPU research code in Julia for solving systems of conservation laws with continuous spectral elements and finite differences in 1D, 2D and 3D.

Install Read the documentation Source code

Features

  • Continuous spectral elements of arbitrarily high order (3rd and above)
  • Time integration through DifferentialEquations.jl
  • DynSGS, a residual-based, parameter-free dynamic subgrid-scale model for shock capturing and stabilization
  • Laguerre semi-infinite elements for outflows and absorbing layers
  • Curved elements and unstructured meshes
  • Proper Orthogonal Decomposition
  • Parallel runs with MPI, and VTK output

Equations

The list below is not closed: the code is built to take arbitrary systems of conservation laws.

  • 1D wave equation
  • 1D shallow water
  • 2D Helmholtz
  • 2D scalar advection-diffusion
  • 2D Euler equations of compressible flows with gravity and passive chemicals
  • 3D Euler equations of compressible flows with gravity

The repository also has examples for magnetohydrodynamics, solid elasticity and shallow water on a sphere. See the gallery.

Quick start

using Jexpresso
Jexpresso.run_case("CompEuler", "sod1d")

This runs the 1D Sod shock tube. Follow the install steps first.
