Install

You need Julia 1.11.9 and Git with SSH access to GitHub. These are the steps for a serial install. For MPI, set it up before step 3 by following INSTALL.md. If something goes wrong, check the FAQ.

1. Clone the code and the sample meshes

git clone git@github.com:smarras79/Jexpresso.git
git clone git@github.com:smarras79/JexpressoMeshes.git

2. Link the meshes

cd Jexpresso
ln -s ../JexpressoMeshes/meshes .

3. Instantiate and precompile

The first precompile takes a while.

julia --project=. -e 'ENV["JULIA_PKG_PRECOMPILE_AUTO"]=0; using Pkg; Pkg.instantiate()'
julia --project=. -e 'using Pkg; Pkg.precompile()'

4. Run a test case

Start Julia with julia --project=. and run:

using Jexpresso
Jexpresso.run_case("CompEuler", "sod1d")

Running in parallel

Once MPI is set up, a case can be launched from the command line, for example on 10 ranks:

mpiexec -n 10 julia --project=. src/Jexpresso.jl MHD fluxEmergenceSon2025
